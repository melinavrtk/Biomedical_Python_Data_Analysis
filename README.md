# Biomedical Python Data Analysis & Data Structures

This repository contains Python scripts developed for biomedical data management, complex data structures manipulation, and automated data pipelines. It showcases the ability to handle raw medical data, build object-oriented structures, and process multi-format datasets.

## Repository Contents

* **`python_basics_control_flow.py`**: Clinical logic implementations, including BMI calculation, patient monitoring loops, and data validation.
* **`oop_patient_student_classes.py`**: Object-Oriented Programming (OOP) for healthcare. Includes `Patient` classes for cholesterol tracking and `Student` structures for health/academic profiling.
* **`file_io_operations.py`**: Automated medical data logging, temperature unit conversions, and text-file data extraction (`.txt`).
* **`numpy_matrices_functions.py`**: NumPy array and matrix operations for rapid statistical extraction from clinical data arrays.
* **`lists_sets_tuples_analysis.py`**: Advanced Python data structures. Features synthetic patient cohort generation, clinical unit overlap analysis using Sets, and feature extraction using Tuples.
* **`multibranch_data_pipeline.py`**: A complete data engineering pipeline using `pandas`. Simulates a central medical center receiving data from 4 branches, merging patient records across **Excel, JSON, XML, and YAML** formats into a unified DataFrame for statistical analysis.
